# Verification Map

This map ties each scheduler verification claim to an executable command and a
durable artifact. Browser IDs prove user-visible behavior. CLI IDs prove backend
truth, local-only guarantees, contracts, and release assumptions.

The `T-SCH-CMD-*` and `T-SCH-PARITY-*` rows are the shared command/CLI/GUI parity
contract: they prove the implemented low-risk GUI handlers and `schedulerctl`
commands route through the same state command model.
