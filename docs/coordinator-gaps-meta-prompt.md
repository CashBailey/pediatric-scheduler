## Investigated root causes (verified by code readers — trust but re-verify the marked items)

### Gap 1 — Paint. Code is NOT gone; two compounding causes:

- **(a) Dead legacy grid renders alongside the new matrix.** `PlanningGridView.swift` `workspace(block:state:)` calls `grid(block:state:)` at **line 299 unconditionally**, as a *sibling* after the `if let projection = activeProjection(block), !projection.dates.isEmpty { PlanningMatrixView(...) }` block (lines 253–298) — not in an `else`. The legacy `grid()`/`PlanningDayRow` path (lines 303–350, 2198–2461) predates paint, knows nothing of `paintOn`/`paintDrag`/`runBatch`, and its per-cell "paint" button just calls `applyPhase` once per click. The matrix is height-capped (`minHeight: 260, maxHeight: 460`) while the legacy grid's ScrollView is unbounded — so the legacy grid dominates the visible area. Introduced in `a0a92b2` (matrix added above the old call, old call never removed), survived `e60200d`.
- **(b) Click-to-paint became opt-in.** In `e60200d`, the matrix `onPaintCell` closure (lines 275–285) only assigns `if paintOn`; `@State private var paintOn = false` (line 26, no persistence). The Paint toggle (lines 121–126, accessibilityIdentifier `planning-grid-paint-toggle`) sits in a `FlexibleWrap` toolbar (`InpatientView.swift:849`) that wraps at whole-group granularity — in a narrow window the toggle can drop to a lower row. Old muscle memory (click cell → paint) now does nothing.
- Working paint machinery to preserve: sweep gesture `PlanningMatrixRowView.canPaintSweep` + DragGesture overlay (1707–1764), `extendPaintSweep`/`commitPaint` (656–709) → `store.runBatch("assign.range", ...)` (`AppStore.swift:145–186`, one undo per stroke), `Model/PaintSelection.swift` (contiguous runs, OP weekend/no-clinic filtering — ports `shared/scheduler/paint-selection.js`).
- **Re-verify at runtime:** launch the app and visually confirm the double-grid rendering and which grid the user actually interacts with; also confirm the user's installed build isn't simply older than `e60200d`.
