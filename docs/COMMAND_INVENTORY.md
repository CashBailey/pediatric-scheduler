# Scheduler Command Inventory

This inventory maps meaningful state-changing GUI actions to the shared command
surface and CLI command forms. "Parity" means current scheduler product behavior
for the listed action, not old Python/Qt parity and not live multi-user sync.

## Deferred State Commands

No deferred state commands are currently tracked here. File review,
drag/drop, selection cleanup, confirmation flows, and visual/PDF acceptance
remain manual or visual-only when they do not create scheduler state truth by
themselves.

## Manual Or Visual-Only

Navigation, theme toggle, modal open/close, roster filters, row collapse,
paint-mode toolbar state, screenshot/PDF visual review, and OS file pickers are
not shared commands. They do not create scheduler state truth by themselves.
